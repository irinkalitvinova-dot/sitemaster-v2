# Бренд «Мастер», версия 2 «Дерзкая»

Версия 1 (спокойная, тёмно-синяя с жёлтым) лежит рядом, в папке `сайт-услуги`. Здесь тот же сайт в другом характере: плакат, толстые чёрные рамки, жёсткие тени, яркие цвета.

## Логотип
`logo.svg` — три блока, сложенные стопкой: фиолетовый, розовый, лимонный, с толстой чёрной обводкой. Тот же образ, что в анимации на первом экране.

## Цвета
| Название | Код | Где используем |
|---|---|---|
| Чёрный | `#0A0A0A` | текст, рамки, жёсткие тени, тёмный блок заявки |
| Лимонный | `#FFE600` | фон страницы, подписи на чёрном |
| Розовый | `#FF3D9A` | кнопки, главный акцент (текст на нём чёрный) |
| Электрик-фиолет | `#5B2EFF` | второстепенный акцент (на нём текст белый) |
| Приглушённый фиолет | `#6B5BD2` | нижний блок с формой (текст на нём белый) |
| Мята | `#6FF0D8` | фон карточки услуги (текст на нём чёрный) |
| Сирень | `#EFE9FF` | плашки и тонкие заливки |
| Белый | `#FFFFFF` | карточки и блоки |

## Шрифты
- Заголовки: **Dela Gothic One** (одно начертание, не делаем жирнее)
- Текст: **Golos Text** (400, 500, 600, 700)

Оба с кириллицей, бесплатные, подключены в `brand.css` через Google Fonts.

## Приёмы
- Рамки 3 px, чёрные. Тени жёсткие, без размытия: `5px 5px 0 #0A0A0A`.
- Заголовки разделов как чёрные плашки с лёгким наклоном.
- Скругления небольшие (8–12 px), кроме круглой наклейки «2–3 дня».

## Голос
Простыми словами, на «вы», без обещаний, которые нельзя проверить. Коротко и по делу.
